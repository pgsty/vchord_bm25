vchord_bm25 1.2.0 updates pgrx to 0.20.0, supports PostgreSQL 15–19 on `x86_64` and `aarch64`, and hardens scan execution and PostgreSQL 18/19 integration.

- Support PostgreSQL 15–19 on `x86_64` and `aarch64` (`pgrx 0.20.0`, Rust 1.99.1+).
- Fix prefilter heap-slot cleanup during error unwinding, remove per-batch `IndexInfo` / `ExecutorState` allocations, and restore `CurrentMemoryContext` on expression evaluation errors.
- Allocate scan descriptors in `es_query_cxt`, wire `Index Searches` (`nsearches`) instrumentation on PostgreSQL 18+, and pass `SO_HINT_REL_READ_ONLY` and static `IndexAmRoutine` on PostgreSQL 19.
- Preserve SQL APIs and format-4 indexes when upgrading in place from 1.0.0 or 1.1.0.

Install the matching package, restart PostgreSQL, and run `ALTER EXTENSION vchord_bm25 UPDATE;` in each database. Existing 1.0.0 and 1.1.0 indexes do not require `REINDEX`.

PostgreSQL 14 is no longer supported by pgrx 0.20.0; upgrade PostgreSQL before installing 1.2.0. Historical 0.3.x (`bm25vector`) installations require data migration and index rebuilding.
