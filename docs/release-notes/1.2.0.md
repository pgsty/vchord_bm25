vchord_bm25 1.2.0 updates pgrx to 0.20.0 and supports PostgreSQL 15–19.

- Add PostgreSQL 19 to the test and Linux package matrices.
- Require Rust 1.99.1 or later and matching Clang, libclang, and LLVM tools.
- Preserve SQL APIs and on-disk index formats when upgrading from 1.1.0.

Install the matching package, restart PostgreSQL, and run `ALTER EXTENSION vchord_bm25 UPDATE;` in each database. No index rebuild is required for the 1.1.0 → 1.2.0 upgrade.

PostgreSQL 14 is no longer supported by pgrx. Upgrade PostgreSQL before installing this release. Earlier extension releases may have additional migration requirements; consult the project migration guide.
